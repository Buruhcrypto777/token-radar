A token launch radar for make.fun's token-radar-01 bounty: it ranks 178 pre-token protocols from the sealed DefiLlama snapshot with a transparent value model (TVL, 7-day growth, age without a token) and a concrete farm plan with cost and time per protocol, plus a sortable, filterable dashboard with a detail view.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
